# Dating MVP Telegram Bot (aiogram)

MVP-бот знакомств, где основной сценарий — **🎮 “Бутылочка” по городу** и дальнейшая **игра знакомства** без раскрытия контактов до взаимного согласия.

## Что реализовано

- Регистрация: имя, возраст, пол, город, описание, фото/голосовое/кружок (опционально).
- Основной путь через кнопку **🎮 Играть в бутылочку**:
  - список лобби по городу пользователя,
  - создание/вход в лобби,
  - запуск и спин бутылочки (MVP: спин от хоста),
  - действия после выбора: симпатия / задание / пропуск.
- Просмотр анкет в городе (`/browse`) оставлен как дополнительный режим.
- Входящий лайк приходит сразу с кнопками:
  - ❤️ Лайкнуть в ответ
  - ❌ Пропустить
- Взаимный лайк => матч (`🎉 У вас взаимная симпатия!`).
- `/matches` — список матчей и действия по статусу.
- Игра знакомства по раундам:
  - текст / голосовое / кружок,
  - ответы передаются анонимно (без форварда профиля),
  - после раунда доступны: следующий раунд / запрос раскрытия контакта / закрыть матч.
- Раскрытие контакта только если оба согласны.

## Команды

- `/start`
- `/bottle`
- `/browse`
- `/matches`
- `/game`
- `/profile`
- `/stop_game`

## Технологии

- Python 3.11+
- aiogram v3
- SQLite (`aiosqlite`)
- FSM
